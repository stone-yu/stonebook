GitHub 仓库更名为 StoneBook

让代码仓库名称、产品名称与用户可见链接保持一致，同时保留对旧配置链接的自动迁移。

状态：ACTIVE创建日期：2026-08-17所属模块：project影响范围：GitHub、前后端链接、开发文档需求来源：用户原话

1. 原始诉求

“github的名字也改一下”

2. 目标与边界

  • 将仓库从 stone-yu/talebook 更名为 stone-yu/stonebook。
  • 同步反馈、欢迎语、徽章、克隆地址和本地远程地址。
  • 不改 Calibre 兼容路径、Python 包名、Docker Hub 旧镜像名和明确指向上游 Talebook 生态的链接。

3. 实现方案

  1. 先确认目标仓库名未占用及当前账号具备管理员权限。
  2. 更新运行时代码和文档链接；旧默认配置同时识别上游地址与旧 fork 地址并迁移到新地址。
  3. 运行前后端定向测试与方案校验，再通过 GitHub API 更名仓库并更新本地 origin。

4. 风险与兼容性

GitHub 会为旧仓库 URL 提供重定向，但本地远程地址仍显式改为新 URL。上游项目、基础镜像及阅读器仓库仍保留其原有名称，避免错误断链。

  • make check-design 与 git diff --check：通过。
  • GitHub 仓库可用性、远程更名及新地址推送：已验证。
