Local Profile 配置文件

用仓库根目录 `.env` 固化非 Docker 开发数据根目录。

创建日期 2026-08-14模块 project状态 ACTIVE后续于 macOS local profile

原始诉求与目标

用户不希望每次在命令前传入 TALEBOOK_LOCAL_ROOT，要求 local profile 支持配置文件。生产配置、Docker Compose 和前端运行参数不应受到影响。

方案

读取启动器读取仓库 `.env`
解析只接受 local profile 白名单键
传递向 Calibre 子进程传入绝对根路径
  • 提供提交到仓库的 .env.example，真实 .env 继续被 Git 忽略。
  • 支持空行、注释、export KEY=value、单双引号；相对路径以仓库根目录解析。
  • 进程环境变量优先于文件，便于 CI 或临时诊断，但正常启动只需 make dev-local。
  • `.env` 缺失时保持当前行为，使用仓库根目录。

风险与错误处理

  • 格式不合法、空值或未知内容不会悄悄改变目录；只读取 TALEBOOK_LOCAL_ROOT 与可选的 Calibre bin 配置。
  • 配置路径会展开 ~ 并转为绝对路径；启动器创建所需子目录。
  • 初始化逻辑区分代码根目录与数据根目录，预置书仍从仓库读取，数据库写入配置的数据根目录。
