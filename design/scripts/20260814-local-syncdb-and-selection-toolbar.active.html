本地缺表修复与选区操作条

创建日期 2026-08-14 · 模块 scripts（影响 app）· 状态 ACTIVE · 来源：用户运行反馈

原始诉求

已有本地数据库调用批注 API 报 no such table: book_annotations；阅读器选中文字后应立即出现可扩展操作条，首个动作是“批注想法”。

方案

  • dev-local 每次启动前执行 SQLAlchemy create_all，只补缺表，不删除或覆盖既有表与数据。
  • 统一批注 SDK 监听普通文档选区；EPUB 内嵌阅读器通过自定义选区事件桥接坐标。
  • 选区形成后在附近显示轻量浮动操作条；点击“批注想法”冻结选区信息、打开批注面板编辑器。操作条按独立动作渲染，便于后续增加划线等动作。

测试结果

  • pytest tests/test_local_development_profile.py tests/test_annotations.py：23 passed。
  • vitest test/utils/talebook-annotations.spec.ts：3 passed，覆盖选区操作条及“批注想法”动作。
  • 两份阅读器 JavaScript 通过 node --check。
  • make dev-local-init 已对实际本地数据库成功执行；SQLite 已确认存在 book_annotations 表。
