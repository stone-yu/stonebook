统一阅读批注与分类浏览

让 EPUB、PDF、TXT 的划线与笔记成为可定位、可跨设备同步、可按个人书架分类回看的私人阅读资产。

创建日期 2026-08-14模块 webserver状态 ACTIVE影响 webserver / app / tests来源 #181 / #943 / 用户 grill

原始诉求与事实

阅读器侧边栏列出本书全部批注，点击可定位；个人书架按分类跨书汇总批注并一步打开书籍定位。仓库已有 design/webserver/20260716-reading-annotations.active.html，仅锁定后端单书 CRUD 且标记待实现，本方案补齐三格式阅读器、分类聚合、删除保护与完整交互；本方案生效后旧方案转为 SUPERSEDED。

已确认决策

格式与类型EPUB、PDF、TXT；划线高亮、针对高亮写笔记、独立章节或页笔记，不混入书签。
分类关系批注动态跟随书籍当前个人分类，不单独复制分类；多分类中重复可见。
生命周期首次批注自动加入书架；移出书架保留为“未归入书架”；删除原书保留快照。
定位降级结构化原生锚点 + 摘录及前后文；失败时近似文本搜索并显式提示。
交互入口桌面左侧栏、移动底部抽屉；书架页“书籍 / 批注”切换；汇总点击新标签打开。
PDF 边界文本 PDF 支持选区；扫描 PDF 支持当前页笔记；不做 OCR、手绘或修改原 PDF。

数据模型

字段用途约束
reader_id / book_id / client_id所有者、当前书籍、客户端幂等键三列唯一；所有接口仅本人可见
kind / content / quote / colorhighlight 或 note、笔记、原文和颜色长度与枚举白名单
format / locatorEPUB CFI、PDF 页/坐标、TXT 偏移的结构化 JSON按格式校验且限制 JSON 大小
prefix / suffix / chapter近似定位上下文和展示信息失败时降级，不静默错跳
book_title / book_authors / book_format / detached原书删除后的私人记录快照不自动关联未来同名书

分类查询通过 shelf_category_books 动态连接，不新增批注分类关联表。

服务与接口

创建验证可读权限并在同一事务自动加入书架
同步按 client_id upsert，后写覆盖
汇总分类树递归查询、分页筛选、失效分组
定位annotation 参数加载目标并调用格式适配器
  • 单书：GET/POST /api/book/<id>/annotations，PUT/DELETE /api/book/<id>/annotations/<id>。
  • 汇总：GET /api/shelf/annotations，支持 category_id、recursive、detached、kind、关键词、分页和排序。
  • 管理员也不能读取其他用户批注；书籍删除时转存快照，不级联清理私人记录。

阅读器架构与视觉计划

新增统一 Annotation SDK，负责同步、侧栏、编辑、重试和状态；EPUB、PDF、TXT 适配器只负责选区、渲染和定位。视觉延续现有阅读器中性色，以页边批注索引为唯一强调：批注色使用纸张标记色，不引入独立品牌主题。桌面为左侧 320px 可折叠栏，移动为底部抽屉；键盘焦点、减少动画和触控尺寸纳入验收。

不做与风险

  • 不做分享、协作、导出、微信读书导入、OCR、手绘和自动重连已删除书籍。
  • PDF.js 与 candle-reader 属嵌入式阅读器，升级时需保留适配器契约；尽量使用公开事件和薄注入层。
  • 格式文件变化会降低定位精度，必须保留原文并显示“近似定位”或“无法精确定位”。
