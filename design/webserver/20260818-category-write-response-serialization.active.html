修复分类写入成功后响应 500

分类新增或移动已经提交数据库，但响应中包含不能直接 JSON 编码的时间对象，导致客户端误判失败并可能重复操作。

状态：ACTIVE创建日期：2026-08-18所属模块：webserver影响范围：分类写接口与响应契约需求来源：用户反馈

1. 原始诉求

“新增分类 和移动分类 都报错：服务器异常，状态码: 500；但是实际好像分类已经新增和移动成功。”

2. 根因证据

create_category() 与 update_category() 先提交事务，handler 随后返回模型 to_dict()。该结果包含 create_time、update_time 的 Python datetime 对象；最小复现确认 Tornado 抛出 TypeError: Object of type datetime is not JSON serializable。

3. 方案

  • 新增统一分类序列化函数，将时间字段转换为 ISO 8601 字符串，保留既有响应字段。
  • 全站分类和个人书架分类的 create/update 响应统一使用该函数。
  • 不改变分类事务、树结构和数据库数据；错误发生在提交后的响应阶段，因此无需数据迁移。

4. 风险与测试

兼容风险低：字段名称保持不变，时间值从不可编码对象变为可用字符串。测试覆盖 LibraryCategory、ShelfCategory、新增、移动及完整 Tornado JSON 编码；同时回归现有分类服务测试。

5. 测试结果

  • 最小复现：新增和移动后的原始 to_dict() 均稳定触发 TypeError: Object of type datetime is not JSON serializable。
