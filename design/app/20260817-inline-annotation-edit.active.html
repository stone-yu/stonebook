已有想法原位编辑

创建日期 2026-08-17 · 模块 app · 状态 ACTIVE · 来源：用户反馈

原始诉求

点击已有想法后，在批注位置显示类似选区操作条的编辑弹窗，不打开左侧批注栏。

方案

  • 复用选区操作条的内联想法编辑器，增加已有批注编辑模式。
  • 点击已有想法时隐藏复制/想法/划线动作，预填原文和想法，只展示编辑表单。
  • EPUB 从高亮 SVG 点击事件计算跨 iframe 坐标；PDF/TXT 使用原文节点坐标。
  • 保存通过现有更新接口写回并刷新高亮，取消仅关闭浮层；侧栏编辑入口保持原有行为。

测试结果

  • Calibre Python 阅读器模板测试：1 项通过，确认内联编辑资源和 EPUB 事件输出。
  • node --check、Python lint、前端 lint 均通过，前端 lint 为 0 错误。
  • npm run build-spa 通过。
