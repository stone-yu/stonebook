同步阅读页批注生命周期与站点图标

让已有想法随阅读器首次渲染自动出现，编辑保存后立即读取新内容，并使独立阅读模板与首页使用同一书架图标。

状态：ACTIVE创建日期：2026-08-17所属模块：app影响：批注 SDK / Candle Reader需求来源：用户反馈

1. 原始诉求

  1. 进入阅读页时已有想法没有展示，必须先从批注侧栏定位一次。
  2. 原位编辑保存后，再弹出的想法仍是编辑前内容。
  3. 阅读详情页的网站图标与首页不一致。

2. 根因

加载时序

批注接口先返回，EPUB rendition 尚未创建；回调退出后没有可靠重试。

对象快照

原文节点监听器闭包保存了绑定时的旧批注对象，reload 后仍读取旧内容。

独立模板

Candle Reader 自己声明旧 ICO，没有使用 Nuxt head 配置。

3. 实现方案

  • 增加幂等的 rendition 就绪轮询；就绪后立即应用已加载批注，并只注册一次 rendered 与 markClicked 监听器。
  • 原文节点只闭包保存批注 ID，每次悬浮或点击通过 SDK 当前 items 查找最新对象。
  • 批注保存后的既有 reload 流程继续作为唯一服务端真值来源。
  • Candle Reader favicon 改为 /logo/bookshelf.svg，并更新静态资源版本参数。

4. 边界与风险

不改变 API 与数据库。轮询仅发生在阅读器启动阶段，并用单一计时器防止并发重试；rendition 实例相同则不会重复绑定事件。批注高亮在每次列表刷新时重新应用，以体现新增与更新。
