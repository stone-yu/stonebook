导航外壳精简方案

创建日期：2026-08-17　所属模块：app　状态：ACTIVE

原始诉求

去除左侧重复且数量错误的“标签导览”，去掉侧栏二维码和页脚 Github、Docker、Project 固定链接，并将头像菜单的反馈地址切换到当前 fork。

目标与决策

区域处理
标签入口保留 /tag，使用 sys.tags；仅从侧栏移除 /nav，不删除路由。
侧栏底部停止渲染 sidebar_extra_html，已有配置继续保留但不再显示。
页脚移除三项固定项目链接，保留管理员配置的页脚正文与额外 HTML。
反馈头像菜单固定跳转 https://github.com/stone-yu/talebook/issues，不影响阅读器等其他可配置反馈入口。

兼容性

/nav 页面与已有书签仍可访问；书库数据、标签数据和 API 均不迁移。自定义主题组件不被强制修改，两个内置页眉和页脚实现保持一致。

测试结果

组件与静态结构测试覆盖唯一标签入口、正确数量来源、二维码隐藏、页脚链接移除及反馈地址。已执行前端定向测试、eslint、SPA 构建、方案校验和浏览器实际渲染检查，结果通过。
