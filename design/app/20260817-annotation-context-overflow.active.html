批注上下文长度溢出修复

创建日期 2026-08-17 · 所属模块 app / webserver · 状态 ACTIVE · 来源：用户实际报错

原始诉求

选中文字添加想法时不应出现“前文长度不能超过500”的错误。

原因与目标

EPUB/PDF 的选区文本与页面文本空白不一致时，查找偏移返回 -1，旧逻辑错误截取了几乎整章作为前文。目标是修正偏移失败分支，并确保异常客户端数据也不会阻断批注保存。

方案

  • 阅读器找不到精确偏移时不生成上下文，仍保留原文和定位器。
  • 前端 SDK 统一将前文保留末尾 500 字、后文保留开头 500 字。
  • 后端对辅助上下文容错截断；原文、笔记和定位器仍按原有规则严格校验。
  • 更新静态资源版本，确保浏览器加载修复脚本。

测试结果

  • npx vitest run test/utils/talebook-annotations.spec.ts：5 项通过。
  • JavaScript 语法、Python lint、相关 Vue eslint、设计文档门禁与差异检查均通过。
