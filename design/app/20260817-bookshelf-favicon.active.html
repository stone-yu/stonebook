统一站点与“我的书架”图标

让浏览器页签中的 Talebook 标识直接复用“我的书架”菜单的书架图形，减少站点标识与产品导航之间的认知差异。

状态：ACTIVE创建日期：2026-08-17所属模块：app需求来源：用户反馈

1. 原始诉求

“网站状态栏图标改一下，改成当前我的书架菜单的图标样式吧。”

2. 目标与边界

目标
  • 浏览器页签使用书架图标。
  • 图形路径与菜单中的 mdi-bookshelf 完全一致。
  • 使用矢量资源，保证高分屏与缩放清晰。
非目标
  • 不修改菜单图标、主题配色或站点标题。
  • 不更换阅读器内书籍封面图标。
  • 不引入远程资源或新增运行时依赖。

3. 现状与实现方案

当前页签引用旧的 /logo/favicon.ico，而“我的书架”使用本地注册的 mdi-bookshelf。新增仓库自有 SVG，以 Material Design Icons 的同一条路径绘制，并把 Nuxt head 中的 favicon 链接切换到该资源。主色采用应用现有的 #1976d2。

4. 兼容性与风险

现代浏览器支持 SVG favicon。资源使用绝对站内路径并随静态产物发布；旧 ICO 文件保留，避免影响仍直接引用它的历史阅读器或 WebDAV 页面。主要风险是浏览器缓存旧图标，可通过硬刷新或重新打开页签更新。

5. 测试结果

验证通过。

  • npx vitest run test/utils/favicon.spec.ts：1 个测试通过。
  • npm run lint：0 error；保留仓库已有的 192 条 warning。
  • npm run build-spa：静态产物生成成功，bookshelf.svg 已进入输出目录。
  • 浏览器实际验证：页面 head 正确声明 SVG favicon；资源返回 200，图形路径、视口与主题色均符合方案。
  • make check-design：通过。
