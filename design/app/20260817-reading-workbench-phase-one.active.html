原始诉求

整体页面入口和配色过于复杂。用户主要关注阅读情况、个人书架以及从书库搜索资源，希望参考简洁、柔和渐变的数据首页完成一期改造。

信息架构

层级内容
一级导航首页、我的书架、找书、更多；管理员额外显示管理入口。
更多分类导览、作者、出版社、标签、文件格式、有声书、排行与系统连接。
找书统一搜索框，本地书库和网络书库作为两个资源来源入口，提供常用元数据筛选捷径。
首页登录用户显示继续阅读、在读/已读/本月完成、书架数量；所有用户显示最近加入。

视觉方案

使用“晨雾书房”方向：浅蓝灰页面底色、低饱和蓝紫/薄荷/暖橙渐变、20px 左右圆角、克制阴影。封面与阅读动作是视觉主角。深色模式使用主题色混合而非写死浅色；移动端以四项底部导航替代常驻侧栏。

数据与权限

复用 /api/index、/api/reading/stats 和 /api/shelf。阅读统计与书架只在登录后请求；游客看到找书与最近加入。第一期不新增阅读时长、连续天数等尚无可靠数据口径的指标。

测试结果

已通过 26 个导航与工作台组件/契约测试；npm run lint 通过（0 errors，保留仓库已有 warnings）；npm run build-spa 构建成功。连接本地真实后端完成浏览器验收：首页、找书页及移动端底部导航均可用，并验证桌面/手机布局和浅色/深色主题。游客首页使用真实书库数据；登录态数据卡片由现有接口及自动化测试覆盖。
