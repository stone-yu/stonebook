PDF 转 EPUB 后的批注跨格式定位

创建日期 2026-08-17 · 所属模块 app · 状态 ACTIVE · 来源：用户实际反馈

原始诉求

书籍由 PDF 转换成 EPUB 后，已有批注仍应能够定位到对应原文。

原因与边界

PDF 定位器是页码与文本偏移，EPUB 定位器是 CFI，两者不能直接换算。已有批注同时保存了原文、前文和后文，因此可用文本锚点做非破坏性降级定位。转换可能改变段落和空白，无法保证像原生 EPUB CFI 一样精确。

实现方案

  • 原生 EPUB 批注优先使用已有 CFI，失败后也进入文本搜索。
  • 跨格式批注按完整原文、空白规范化文本、中文紧凑文本及长文锚点依次匹配 EPUB spine。
  • 找到后使用搜索结果产生的临时 CFI 打开章节并标记原文，返回“近似定位”。
  • 不改写数据库中的原格式和定位器，确保继续用 PDF 阅读时仍可精确定位。

测试结果

  • npx vitest run test/utils/talebook-annotations.spec.ts：6 项通过，覆盖跨格式候选、空白差异、长原文锚点和既有批注行为。
  • pytest -q tests/test_annotations.py tests/test_categories.py tests/test_local_development_profile.py：36 项通过。
  • JavaScript 语法与相关 Vue eslint 通过；真实后端 EPUB 阅读页加载 2 个内容 iframe，批注入口正常且控制台无错误。
  • 浏览器会话未登录，无法用用户私有批注完成端到端点击；跨格式搜索由组件测试和真实阅读器资源加载共同验证。
