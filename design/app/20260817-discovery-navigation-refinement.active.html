找书导航收敛

创建日期：2026-08-17　模块：app　状态：ACTIVE　来源：一期体验反馈

原始诉求

找书进入搜索结果、本地书库、网络书库及元数据筛选页面后缺少返回入口；“我的书架”名称偏长；筛选入口同时出现在找书与更多，造成信息架构重复。

目标

找书
承接全部资源发现与筛选
书架
缩短一级导航名称
更多
仅保留工具与低频阅读功能

方案

区域调整
找书子页面统一显示固定返回“找书”的轻量按钮，避免依赖不稳定的浏览器历史。
找书入口保留搜索、本地书库、网络书库，并集中分类、作者、出版社、标签、格式、系列和评分筛选。
更多移除全部书籍筛选入口，仅保留有声书、热门、最近加入、OPDS 和 WebDAV。
一级导航中文“我的书架”改为“书架”，英文同步改为 Shelf。

数据与兼容性

不新增接口和路由；返回入口固定指向 /discover。现有筛选页面地址保持不变，旧书签和外部链接继续可用。

测试结果

29 个导航与工作台组件/契约测试通过；npm run lint 通过（0 errors，保留仓库已有 warnings）；npm run build-spa 构建成功。连接真实后端完成桌面浏览器验收：找书页展示七类筛选入口，本地书库显示并可点击“返回找书”，更多页不再出现筛选菜单；手机 390×844 视口验证搜索结果页返回入口及“书架”文案正常。
